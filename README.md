# 🛒 Smart Price Tracker & Deal Alert System

> A Java-based price tracking application that helps users monitor products, track price changes, calculate savings, and identify the right time to buy.

---

## 🚀 Project Overview

**Smart Price Tracker** is a menu-driven Java application designed to manage product prices and notify users when their desired target price is reached.

The project demonstrates practical implementation of **Object-Oriented Programming, Collections, CRUD operations, Searching, Sorting, Exception Handling, and File Handling**.

---

## ✨ Features

| Feature | Description |
|---|---|
| ➕ Add Product | Add products with price details |
| 🔍 Search Product | Search using Product ID |
| 👀 View Products | Display all tracked products |
| ✏️ Update Price | Update current and target price |
| 🗑️ Delete Product | Remove a product |
| 📊 Sort Products | Sort products by current price |
| 📈 Price History | Track previous and current prices |
| 💰 Savings Calculator | Calculate amount saved |
| 📉 Discount Calculator | Calculate discount percentage |
| 🔔 Deal Alert | Alert when target price is reached |
| 💾 File Storage | Save product data to a file |
| 📂 Data Loading | Load saved products when application starts |
| 🛡️ Exception Handling | Handle invalid user input |
| 🚫 Duplicate Validation | Prevent duplicate Product IDs |
